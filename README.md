# Manitoba Aerospace & Defence: new website, Phase 1 preview

A static snapshot of the Phase 1 WordPress build, for review only. Not indexed by search engines.

- The real site is a WordPress theme with every section editable in wp-admin (ACF), plus an importer that moves all current mbaerospace.ca content across.
- Forms and site search need WordPress, so on this preview they show a note instead of sending.
- Photos are Wikimedia Commons stand-ins, credited on each page.
